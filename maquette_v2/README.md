# BienDecider V3.7

Cette version repart de la logique V3.5 et ajoute uniquement les éléments manquants du diagnostic :

- fil Paul avec décisions, insights et résultats ;
- équipe backstage ;
- brief hebdomadaire ;
- missions orientées résultats ;
- CR d'audit initial ;
- diagnostic vivant ;
- provenance et fraîcheur ;
- évolutions depuis l'audit ;
- sources et connecteurs ;
- lien entre insight et mission.

Ouvrir `index.html` ou lancer `python -m http.server 8080`.
